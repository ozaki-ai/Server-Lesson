# ＜cd＞
- ディレクトリ移動する

# ＜pwd＞
- 現在いる位置を確認

# ＜ls＞
- 今いるディレクトリの中にあるフォルダとかファイル一覧を確認
(-aで隠しディレクトリとかファイルも閲覧できる)

# ＜./＞
- 現在いる位置

# ＜../＞
- 一つ上のディレクトリ

# ＜mkdir＞
- フォルダ作成する

# ＜touch＞
- ファイル作成

# ＜絶対パス＞
- 位置に関係なく一番上の階層から目的に位置までいくこと

# ＜相対パス＞
- 自分が今いる位置から目的の位置までいくこと

# ＜演算子＞
- 左のコマンドが成功してれば右を実行できる仕組み

# 例・cd /home/test1 && ls
- 「cd /home/test1」でtest1というディレクトリを参照して、lsを実行してる


# ＜cp＞
- ファイルあるいはディレクトリのコピー

- 例・cp コピー元 コピー先
- 複製することになるのでコピー先は新しく作成されている
- (-rをつければディレクトリごと複製できる)


# ＜mv＞
- ファイルやディレクトリの移動を行う、ショートカットキーでいう切り取り

- 例・mv 変更元 変更先
- この変更先というのは移動後の名前、新しい場所で、既に存在する名前ならその配下にいく


# ＜rm＞
- ファイルの削除、-rをつけるとディレクトリの削除


# ワイルドカード
- ＊はそれ以外の部分をヒットさせる、?は一か所だけ指定してそれ以外をヒット

# ＜>＞
- ファイルの内容をコピペできる(内容全部書き換わる)

- 例・実行結果の出力 > 書き換えるファイル名
- 書き換わるファイル名は、存在しないファイル名の場合は作成される



# ＜>>＞
- ファイルの末尾に内容をコピペできる

- 例・実行結果の出力 >> 書き換えるファイル名


# ＜cat＞
- ファイルの内容をターミナル上で確認できる


# ＜vim＞
- ファイルの内容をエディタで開いて編集とかできる

- 操作方法

- ノーマルモード
- escキー・編集はできない、移動とか検索とか削除
- j下・k上・h左・l右
- :wで保存・:wqで保存終了・:q!で保存しないで終了


- インサートモード
- i・編集できる
